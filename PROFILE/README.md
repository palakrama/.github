# palakrama 🚀
organize ini untuk pengembangan palakrama & sebagai acuan konsistensi di setiap modul/service. 
- **backend:** go, python
- **frontend:** react, js
- **system:** linux
- **tooling:** nvim, dbeaver

### 📖 service
- [**auth:**](https://github.com/palakrama/auth) manajemen autentifikasi akun user
- [**stats:**](https://github.com/palakrama/stats) penyimpanan statistik & kehadiran halaman
- [**communication:**](https://github.com/palakrama/communication) pesan ke user; verifikasi & notifikasi
- [**rsvp:**](https://github.com/palakrama/rsvp) manajemen rsvp dari guest sampai terdaftar
- [**analytic:**](https://github.com/palakrama/analytic) -

### 📖 packages
- [**site:**](https://github.com/palakrama/site) manajemen host; ex: palakrama.id/site/{hostname} -> {hostname}.palakrama.id/
- [**templates:**](https://github.com/palakrama/templates) portofolio
