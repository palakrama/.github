# Panduan Kontribusi Palakrama

Terima kasih sudah berkontribusi! Agar alur kerja tim tetap rapi, ikuti aturan dasar berikut:

### 1. Penamaan Branch
- Fitur baru: `feat/nama-fitur`
- Perbaikan bug: `fix/deskripsi-singkat`
- Dokumentasi: `docs/hal-yang-diubah`

### 2. Standar Commit Message
Gunakan format Conventional Commits:
- `feat: tambah endpoint autentikasi`
- `fix: tangani null pointer pada handler`
- `refactor: sederhanakan fungsi parser`
- `docs: update instruksi instalasi pada README`

### 3. Alur Kerja (Workflow)
1. Buat branch baru dari `main`.
2. Lakukan perubahan kode dan selesaikan pengujian lokal.
3. Buat Pull Request ke `main` dan minta setidaknya 1 anggota tim untuk mereview.
